# Option selection and confirmed orders — October 3, 2026

Includes Claude options-sheet/order-flow work plus release hardening. Requires
backend PR30, deployed as 17b2291b4fa74ff70d6ed1ec04d41e222440a76d.

- Configure nested options from the backend's verified reference tree.
- An unavailable option tree cannot silently become a base-price basket.
- Repeated differently configured lines of the same item are rejected explicitly.
- Incomplete platform configurations remain unranked. A single verified platform
  does not imply the restaurant only exists on that platform. Equal totals tie.
- Order links retain a pending basket; return confirmation records the amount the
  user confirms paying. Reported price differences require amount entry, and
  savings are recalculated rather than preserving a quoted saving.
- Confirmed orders stay on the device; limited feedback and app events are sent
  to the backend. Native external-app return QA and privacy notice review remain
  required before a friends-and-family/public distribution.
